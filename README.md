# dwg2ifc — lataukset

Tästä saat **dwg2ifc**-ohjelman (AutoCAD DWG/DXF → IFC4 -konvertteri
kylmälaitesuunnitteluun).

## Lataa ohjelma

1. Avaa **[Releases-sivu](https://github.com/radika-oy/dwg2ifc-dist/releases/latest)**.
2. Lataa uusin `dwg2ifc-x.y.z.exe`.
3. Tuplaklikkaa — ohjelma käynnistyy, ei erillistä asennusta.

> **Windows SmartScreen voi varoittaa** ("tuntematon julkaisija") ensimmäisellä
> avauksella, koska ohjelmaa ei ole erikseen allekirjoitettu. Klikkaa
> *Lisätiedot → Suorita silti*. Tämä kysytään vain kerran.

## Päivitykset tulevat automaattisesti

Kun ohjelma on kerran asennettu, **se hakee päivitykset itse**. Aina kun
uusi versio julkaistaan, ohjelman yläreunaan ilmestyy keltainen palkki:
*"Uusi versio saatavilla — Päivitä nyt"*. Yksi klikkaus lataa ja vaihtaa
uuden version. Sinun ei tarvitse käydä täällä uudelleen.
